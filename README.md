# dotfiles

Single source of truth for this CachyOS (Hyprland + Noctalia) gaming machine.
Configs live here, are versioned with git, and are symlinked into place with
[GNU Stow](https://www.gnu.org/software/stow/).

## Layout

```
dotfiles/
├── install.sh          # install packages, then link configs
├── link.sh             # symlink stow/* into $HOME (backs up anything in the way)
├── packages/
│   ├── pacman.txt      # official repo packages
│   └── aur.txt         # AUR packages (installed with paru)
└── stow/               # one folder per app, each mirrors $HOME
    ├── hypr/.config/hypr        -> ~/.config/hypr
    ├── fish/.config/fish        -> ~/.config/fish
    ├── kitty/.config/kitty      -> ~/.config/kitty
    └── ...
```

Each app folder is linked as a whole directory (`~/.config/kitty -> ~/dotfiles/stow/kitty/.config/kitty`),
so editing a file in either place edits the same file, and new files an app creates land in the repo.

## Fresh machine

```sh
sudo pacman -S --needed git
git clone <your-remote> ~/dotfiles
cd ~/dotfiles
./install.sh
```

## Day to day

| Task | Command |
| --- | --- |
| Edit a config | edit it in `~/dotfiles/stow/...` (or via `~/.config/...` — same file), then `git commit` |
| Add a package | add a line to `packages/pacman.txt` or `packages/aur.txt`, run `./install.sh packages` |
| Track a new app's config | `mkdir -p stow/<app>/.config && mv ~/.config/<app> stow/<app>/.config/ && ./link.sh <app>` |
| Re-link everything | `./link.sh` |
| Unlink an app | `./link.sh -D <app>` |

Anything that was in the way when linking is moved to `~/.dotfiles-backup/<timestamp>/`.

## Not tracked (see .gitignore)

- `fish_variables` — rewritten by fish constantly.
- Noctalia theme files (`kitty/themes/noctalia.conf`, `alacritty/themes/noctalia.toml`,
  `btop/themes/noctalia.theme`) — regenerated by Noctalia from your colors/wallpaper.

## App notes

- **Steam** — from `multilib`. NVIDIA 32-bit drivers (`lib32-nvidia-utils`) come with CachyOS.
- **Discord** — runs natively on Wayland via `ELECTRON_OZONE_PLATFORM_HINT=auto` (set in `uwsm/env`).
- **1Password** — AUR. `install.sh` imports 1Password's signing key before building.
  Started silently in the tray from `hypr/config/autostart.lua`. "Unlock with system authentication"
  needs a polkit agent, provided by `hyprpolkitagent` (also started from autostart).
